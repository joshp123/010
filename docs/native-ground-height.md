# Native ground height interpretation

Written by AI on 2026-10-24 by model GPT-6.

`public/ground-height-filter.js` omits untrustworthy triangles from the native Rotterdam BGT ground model before styling and bridge-source fusion. It changes only the draw index. Source positions, normals, feature identifiers and original index attributes remain available; `originalGroundIndex(geometry)` returns the source index. Each model records separate omission counts in `model.userData.groundHeightFilter`. Tile disposal retains the existing geometry lifecycle.

Exact −99.99 m missing-height triangles are omitted in every class. This includes structural features: a real quay wall can still have a missing lower coordinate, which must not become a 100 m wall. Additional interpretation applies to BGT green/unvegetated terrain, roadway/supporting roadway, and water/supporting water surface classes. Features classified as quay, wall, sheet pile or retaining wall are excluded from that surface interpretation. A triangle is omitted if:

- Any reconstructed source height is within 1 cm of −99.99 m.
- Any source height is below −30 m and the feature is a surface class **or** the same source feature demonstrably contains an exact missing-height anchor. This covers malformed interpolated missing heights, including those in structural features.
- It belongs to a surface class, its height range exceeds 1 m and its minimum horizontal triangle altitude is below 5 cm, identifying nearly vertical surface curtains.

Heights are reconstructed from the model's ECEF coordinates using the WGS84 ellipsoid. Plan distances use geographic longitude/latitude, independent of vertex height. Local tangent-frame Y is not used: Earth curvature produces substantial negative local Y at the coast even for valid ground. Any parent renderer frame is removed before reading the model's native transform, so attachment to the local scene cannot change the decision. The `colorModel` load hook applies filtering before source fusion. Per-layer diagnostics aggregate the reconstructed height range, parent attachment count and omission categories.

The −30 m boundary is a source-specific interpretation, **not a documented publisher contract**. Actual port samples contain repeated −99.99 m coordinates and interpolated levels −66.83, −50.25, −50.21 and −47.42 m. Some malformed triangles span tens of metres horizontally; a vertical-curtain test alone cannot remove them. Keeping these known false ramps would distort the surface. The filter instead leaves holes for the cartographic fallback. It does not raise coordinates or invent measured terrain. Valid negative ground above −30 m survives unless it is a nearly vertical face of a two-dimensional surface class. Deep structural geometry without missing-height evidence remains untouched.

Existing Gemeente Rotterdam source attribution applies unchanged. The [publisher's source description](https://www.rotterdam.nl/rotterdam-in-3d) describes BGT and measured acquisition methods, but does not establish a missing-height encoding.

The first six port samples contain 5,240 triangles. The filter omits 1,807 triangles touching exact missing heights and 383 touching malformed interpolated heights. Further inspection of actual loaded port tiles found `33497/6924.b3dm`, feature `DGDT_ID=16116903`, classified `Scheiding/Kademuur`, spanning −99.99 to +4.57 m. This explained giant walls surviving the earlier structural exemption; preserving a class cannot mean preserving its missing coordinates. Separate native Erasmus and dune samples exercise ordinary negative ground and the vertical-curtain rule. Every retained triangle was checked against the original indices in original order; position attributes remain identical. A 28,652-triangle sample took approximately 23 ms to process in Node. This is a one-time tile preparation cost, not a browser frame-latency result. 

This module is specific to the native BGT ground source. The compact green-terrain preparation applies the equivalent interpretation independently, before generating its source-derived assets. Replacing either interpretation must preserve the original source and explicitly reconsider the height cutoff and surface semantics.
