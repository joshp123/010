# Adjoining municipal source for model interpretation

`prepare-adjoining-source.py` selects **all finest leaves intersecting a geographic envelope**, retaining acquisition through the existing municipal source cache. It uses the current textured edition and shared hierarchy, not a list of specially chosen houses. It writes complete original leaf GLBs, original compressed image bytes, source BAG/batch/material/primitive/triangle bindings, and five shared views (opposing front/back directions plus roof). Geometry, normals, UVs and source imagery remain the fallback. No model result or new architectural detail is manufactured.

```
python scripts/prepare-adjoining-source.py \
  --bounds 4.4465 51.90925 4.4479 51.91005 \
  --output work/adjoining-source --size 2048 --panel-size 768 --acquire
python tests/adjoining-source.py work/adjoining-source
```

Omit `--acquire` for an offline rebuild. Change bounds for the next area; the default12-leaf bound prevents accidental municipality-wide downloads, and `--max-tiles` explicitly changes it. Raw inputs and HTTP provenance remain under `source-data/current-building-appearance/raw/`. Current source is CC BY4.0, Gemeente Rotterdam; the dataset-specific catalog evidence is `source-data/current-building-evidence/catalog-evidence.json`. Photo capture dates remain unknown. Source hash mismatches fail instead of silently reinterpreting new bytes.

The demonstrated adjoining envelope selects six level18 leaves,117BAGs and6,284triangles,47,215,568 decoded raw bytes. Native leaf extents extend beyond the requested rectangle to retain complete source features and their neighbors. `binding.json` preserves each source bounding volume, RTC, batch table and original image/material indices. All leaves are transformed through their original node matrices and RTC into **one** ECEF-anchored east/up/south frame. Cameras share one scale and centre: buildings are never separately fitted. Native geometry is retained in separate original GLBs; do not concatenate their local coordinates without the supplied transforms.

Each shared view's compressed projection NPZ contains source triangle index, UV, depth and exact source texel. The exact texel avoids ambiguity where floating-point inverse projection falls on an integer atlas boundary. `source-triangles.npz` and `binding.json.triangleBindings` resolve each visible sample back to original tile, node, mesh, primitive, source triangle indices, material, batch and BAG. Camera and inverse matrices define pixel-centre conventions explicitly. Uncovered pixels have index−1/NaN and untextured surfaces carry no invented UVs.

Overlapping `panels/` are literal crops from these shared views, with their crop coordinates and adjusted camera matrices in `modelPanels`. They retain adjoining context instead of independently centring each house. Feed these same-size images to the existing pinned local MFLUX flow; retain source/style/model/seed/prompt and candidate hashes. The current `run-mflux-pilot.py` and bake helper remain deliberately pilot-specific: this package does **not** claim automatic multi-view model consistency or expand their edit authority. A candidate must preserve exact panel alignment and be reviewed together with neighboring panels and opposing source views. Visibility is not a semantic edit mask. Do not automatically bake shared/occluded atlas texels, illegible text or uncertain party walls. The exact identity/UV maps permit a separately reviewed transfer without changing geometry.

The actual source contact sheet reveals detailed roofs, attached street rows and courtyards, but also important interpretation ambiguities: BAG0599100000638397 carries extensive road/ground-like imagery, and its source attributes place both lowest and highest floors at−1 (Jan Kruijffstraat55). It may represent an underground structure beneath public space; a flat textured plate is not by itself proof of erroneous geometry. Some rear/party surfaces smear or occlude architecture. Retain these observations for independent review rather than inventing above-ground buildings or assuming every BAG feature should become a house. Source views omit the independent ground/vegetation layers; the shared geographic frame permits their later inclusion. Six source leaves do not establish municipality-wide coverage or final visual quality.

Validation checks every expanded source triangle's position/UV/material/BAG mapping, retained source/image hashes, and10,000+ view pixel correspondences including exact sampled color and inverse-projected position. Panel crops preserve shared pixels exactly. These establish deterministic binding, not art acceptance or GPU/runtime appearance.
